# Smart Automatic Power Factor Correction System

## 📌 Project Overview

This project presents the design of a Smart Automatic Power Factor Correction System for improving the power factor of an electrical load.

The system monitors the electrical parameters and automatically controls a capacitor bank to compensate for reactive power.

## 🎯 Objectives

- To improve the power factor of electrical loads.
- To reduce reactive power demand.
- To improve electrical system efficiency.
- To reduce unnecessary current flow.
- To demonstrate automatic capacitor-bank control.

## ⚡ Basic Principle

Power factor is the ratio of real power to apparent power.

**Power Factor = Real Power / Apparent Power**

When an inductive load operates with a low power factor, additional reactive power is required. Capacitors are used to compensate for this reactive power and improve the power factor.

## 🔧 Proposed System

The proposed system consists of:

- Voltage and current sensing
- Microcontroller
- Relay control
- Capacitor bank
- Electrical load
- Power factor monitoring

The controller monitors the power factor and switches the required capacitor stages through relays.

## 🔄 Working Principle

1. The electrical load is connected to the system.
2. Voltage and current parameters are monitored.
3. The power factor is determined.
4. The controller compares the measured value with the desired value.
5. If the power factor is low, a capacitor stage is switched ON.
6. The process is repeated automatically.
7. The objective is to maintain an improved power factor.

## 🧩 Main Components

## 📊 Expected Result

The system is designed to improve the power factor by automatically switching capacitor stages according to the load condition.

The actual performance depends on the selected components and electrical load.
